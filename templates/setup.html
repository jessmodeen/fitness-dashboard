1

Configure your API credentials

Open the file .env (in your fitness-dashboard folder) in any text editor and fill in the following:

🟣 Whoop API

  1. Go to developer.whoop.com and sign in with your Whoop account
  2. Click Create Application
  3. Set the Redirect URI to exactly: http://localhost:5000/auth/whoop/callback
  4. Copy your Client ID → paste as WHOOP_CLIENT_ID
  5. Copy your Client Secret → paste as WHOOP_CLIENT_SECRET

🟠 Strava API

  1. Go to strava.com/settings/api and sign in
  2. Fill in any name for your app; set Authorization Callback Domain to localhost
  3. Copy your Client ID → paste as STRAVA_CLIENT_ID
  4. Copy your Client Secret → paste as STRAVA_CLIENT_SECRET

🤖 Anthropic (Claude AI)

  1. Go to console.anthropic.com and sign in
  2. Click API Keys → Create Key
  3. Copy the key → paste as ANTHROPIC_API_KEY

🔑 Flask Secret Key

  1. In your terminal, run: python3 -c "import secrets; print(secrets.token_hex(32))"
  2. Copy the output → paste as FLASK_SECRET_KEY

After editing .env, restart the dashboard (stop with Ctrl+C and run python3 app.py again) so it reads the new values.
