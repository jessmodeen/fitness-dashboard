# Privacy Policy

**Last updated: May 17, 2026**

## Overview

This is a personal fitness dashboard application built for private, single-user use only. It is not a commercial product and is not available to the public.

## Data Collection

This application accesses the following data from WHOOP via the WHOOP API:

- Recovery scores
- Sleep performance data
- Heart rate and strain data
- Workout data

## How Data Is Used

All data retrieved from WHOOP is used solely to generate personalized training recommendations for the application owner. Data is:

- Used only by the individual who owns both this application and the connected WHOOP account
- Never shared with any third party
- Never sold or used for advertising
- Never used to train machine learning models

## Data Storage

Data is stored locally on the application owner's personal computer only. It is not transmitted to any external server beyond what is necessary to communicate with the WHOOP API.

## Third Parties

This application does not share any user data with third parties. The only external service this application communicates with is the WHOOP API, as authorized by the account owner.

## Contact

This is a personal project. For questions, contact the application owner directly.
